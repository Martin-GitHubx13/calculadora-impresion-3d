# Calculadora de Costos de Impresión 3D

Una calculadora sencilla para estimar los costos y el precio de venta de piezas impresas en 3D.

## 🌐 Usar la calculadora

**[Abrir la calculadora](https://martin-githubx13.github.io/calculadora-impresion-3d/)**

No necesitas descargar nada. La calculadora funciona directamente desde el navegador.

## ✨ Características

* Cálculo del costo del filamento.
* Estimación del costo de impresión.
* Cálculo del precio de venta.
* Cálculo de ganancias.
* Interfaz sencilla y rápida.

## 🖨️ Proyecto

Creado por **Martin-GitHubx13**.

El proyecto está pensado para ayudar a quienes imprimen en 3D a calcular cuánto cuesta realmente producir una pieza.
