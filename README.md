# 🖨️ Calculadora de impresión 3D

Una calculadora web para estimar el costo real de una impresión 3D.

Permite calcular de forma sencilla cuánto cuesta producir una pieza considerando diferentes factores, como el filamento, consumo eléctrico, tiempo de impresión, desgaste de la impresora y margen de ganancia.

## ✨ Características

- 🧵 Cálculo del costo del filamento
- ⚡ Estimación del consumo eléctrico
- 🖨️ Diferentes modelos de impresoras
- ⏱️ Cálculo según horas y minutos de impresión
- 🔧 Costo estimado de desgaste de la impresora
- 💰 Margen de ganancia configurable
- 📦 Cálculo por cantidad de piezas
- 🧾 Generación de cotizaciones
- 🌎 Varias monedas
- 🌙 Modo oscuro y claro
- 💾 Guardado de configuración en el navegador
- 📱 Diseño adaptable para celular y PC
- ☕ Opción de apoyar el proyecto mediante donaciones
